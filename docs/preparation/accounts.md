# 账号、预注册与个人信息

## 新生入学注册包括什么

2026 级新生入学注册包括以下五个环节：

1. **网上预注册：**先激活 IT 账号并配置 MFA，再在 NottinghamHub 完成注册；
2. **个人信息填写：**登录 Application Hub 填写并核对个人信息；
3. **网上选寝：**在规定时间内通过 Application Hub 选择寝室；
4. **现场注册报到：**携带纸质新生注册单及其他材料到校办理手续；
5. **办理寝室入住：**完成现场注册后，前往对应寝室楼办理入住。

新生入学阶段会使用多个名称相近、用途不同的系统：

| 系统 | 主要用途 | 2026 级使用时间 |
| --- | --- | --- |
| [IT Accounts](https://itaccounts.nottingham.ac.uk/) | 激活学校 IT 账号 | 8 月 11 日起 |
| 学校邮箱 | 接收注册邀请、报到、课程和学院通知 | 账号激活后立即开始查看 |
| [NottinghamHub / MyNottingham](https://mynottingham.nottingham.ac.uk/) | 完成网上预注册，入学后办理学生事务 | 8 月 11 日起按新生类型开放 |
| [Application Hub](https://oaas.nottingham.edu.cn/#/new-student/login) | 填写个人信息、网上选寝、打印新生注册单、提交延期报到申请 | 8 月 11 日起按阶段开放 |
| [Moodle](https://moodle.nottingham.ac.uk/) | 访问学院衔接课和入学后的课程资料 | IT 账号激活后 |

!!! danger "每天至少检查两次学校邮箱"
    IT 账号激活后，建议每天早晚各检查一次学校邮箱。报到、课程、iWeek 和学院的重要通知都会通过学校邮箱发送，请不要只查看个人邮箱或微信群。

## 网上预注册

请在以下时间内完成网上预注册，否则将影响正常入学及校内各项服务和设施的使用：

| 新生类型 | 办理时间 |
| --- | --- |
| 本科新生 | **2026 年 8 月 11 日—9 月 3 日** |
| 硕博新生 | **2026 年 8 月 11 日—9 月 18 日** |

完成网上预注册前，请先开通学校账号，再按照邀请邮件进入 NottinghamHub。

### 开始前：激活 IT 账号并登录学校邮箱

学校邮箱是新生在宁波诺丁汉大学学习生活的重要工具，也是与学校各部门沟通的首要渠道。请先完成 IT 账号激活、修改初始密码并配置多因素身份验证（MFA），再确认能够登录学校邮箱。

[查看 IT 账户激活与 MFA 图文指南](account-activation.md){ .resource-link }

账号激活问题可联系 [itservicedesk@nottingham.edu.cn](mailto:itservicedesk@nottingham.edu.cn)。

### 在 NottinghamHub 完成网上注册

账号激活后，NottinghamHub 会自动向学校邮箱发送“注册邀请”。打开邮件中的邀请链接，使用完整学校邮箱地址和修改后的新密码登录，并按页面提示完成全部注册内容。

[查看 NottinghamHub 网上注册图文指南](nottinghamhub-registration.md){ .resource-link }

[打开 NottinghamHub](https://mynottingham.nottingham.ac.uk/){ .resource-link }

注册问题可联系 [Academic-Service-Office@nottingham.edu.cn](mailto:Academic-Service-Office@nottingham.edu.cn)。

## 在 Application Hub 填写个人信息

| 新生类型 | 填写时间 |
| --- | --- |
| 本科新生 | **2026 年 8 月 11 日—9 月 3 日** |
| 硕博新生 | **2026 年 8 月 11 日—9 月 18 日** |

Application Hub 使用学校邮箱账号和密码登录。只有完成个人信息填写的新生，才能在后续注册步骤中打印用于现场报到的新生注册单。

[打开 Application Hub](https://oaas.nottingham.edu.cn/#/new-student/login){ .resource-link }

!!! warning "保护账号"
    不要将账号密码、短信验证码或登录二维码发送给他人。学校不会要求你通过共享屏幕、远程控制或向私人账户转账来“激活”账号。
